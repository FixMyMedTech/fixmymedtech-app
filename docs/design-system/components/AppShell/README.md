# AppShell

Every signed-in page: a top bar with the colour mark and name, the avatar menu on the right, a sidebar of Lucide icons with labels, and the page in `shell-main`.

- Active page: `primary-tint` with `primary` text. Icons 18px, 2px stroke, `currentColor`; no emoji.
- Phones: the sidebar becomes a drawer. Folded on desktop: icons only, each link keeps a `title`.

# Card

The one container for a topic on a page. `h3` title, then content; no hairline under the title.

- `card-stat`: a dashboard counter: eyebrow, `display` number, one `small` line. Its top edge uses the status colour of what it counts (`is-ok`, `is-warn`, `is-danger`, `is-total`). Four per row at most.
- Never nest cards; separate parts inside with spacing.

**What the consumer provides:** title and content, or label, number and context line.

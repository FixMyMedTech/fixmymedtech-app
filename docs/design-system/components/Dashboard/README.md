# Dashboard

The clinic's day on one screen, top to bottom:

1. **Hero** with "Hello {name}", the share of working devices, a meter and four pieces: working, being serviced, broken down, service overdue.
2. **Needs you today**: section head with a flag icon tile and a count badge; one row per item with a coloured left edge and one button.
3. **Your devices by ward**: the wall, one sunken card per ward with a dot chip per device.
4. **Numbers and map** folded.

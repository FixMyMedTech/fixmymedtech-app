# Field

A label, a control (`input`, `select` or `textarea`, all with class `input`) and optional help text. Fields sit in a `field-row` when two are short; rows stack on phones.

- Every field has a visible label. Placeholders only show an example.
- Errors go in the help line in `danger`, saying how to fix it.

**What the consumer provides:** id, label key, value, help text.

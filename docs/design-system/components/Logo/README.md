# Logo

One mark (health cross, heartbeat line turning into a wrench, gear) in three renderings, plus the name under or beside it.

- **Colour:** cross and pulse line in the brand gradient (`brand-teal` to `brand-deep`), gear in `brand-navy`. On white and light grounds only.
- **Black:** everything `#000000`. Print, stamps, QR tags, fax.
- **White:** everything `#FFFFFF`. On `brand-navy`, `brand-deep`, the gradient and photos.
- **Name:** always FixMyMedTech, one word, mixed case, `brand-navy` with "My" in `accent`. Always placed as part of the logo image, never retyped.

Rules: clear space `space-12` around a stand-alone logo; minimum 24px high on screen, 10mm in print; no recolouring, stretching, outlines or shadows. Avatars, favicons and app icons use the mark alone.

The current colour mark is a raster of the old drawing (teal `#03A5B4` to blue `#026FA8`). Redraw it as a vector in the brand gradient before printing anything large.

**What the consumer provides:** `alt="FixMyMedTech"`, or empty `alt` when the name is written next to it.

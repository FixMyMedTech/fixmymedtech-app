# PublicDevicePage

The page behind every QR tag, usually opened on a phone in a ward. Phone-first, `page-narrow` wide.

- Header: `brand-deep` with the white mark and name, and a 4px brand-gradient rule under it. Text never sits on the teal end of the gradient.
- Identity: category as eyebrow, device name as `h2`, short id and location as `small`, status badge on the right.
- If the device is out of service, the `warn-bar` comes before anything else.
- One primary action: "Report fault".

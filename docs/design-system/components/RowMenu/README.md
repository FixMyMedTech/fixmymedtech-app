# RowMenu

Secondary row actions behind "⋯", so each row shows one button.

- `details.rowmenu` with a 34px summary holding the Lucide `more` icon and an `aria-label`.
- The pop-over is a `surface` menu with `shadow-float`; destructive items use `.danger` (red text, red tint on hover).
- Destructive actions still confirm in a dialog.

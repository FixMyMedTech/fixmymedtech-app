# Table

Lists of devices, faults and members. Header in uppercase `small` on `sunken`; first column is the name in `text`; codes in `code`.

- Below 768px, rows become stacked cards (`has-cards` in the app).
- Row actions: `btn-secondary btn-sm` in the last column.

**What the consumer provides:** columns, rows, and an empty-state sentence ("No devices found.").

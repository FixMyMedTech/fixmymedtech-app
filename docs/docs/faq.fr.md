# Questions et problèmes

<div class="in-app all" markdown>**Dans l'application :** le bouton **?** en bas à droite de chaque page permet d'**Envoyer un commentaire** ou de **Signaler un problème** si votre question n'est pas ici.</div>

## Entrer dans l'application

### Je ne vois pas l'onglet Travail { #i-dont-see-the-work-tab }

Les onglets **Équipements**, **Travail** et **Communauté** apparaissent quand vos trois étapes d'accueil sont terminées. D'ici là vous êtes **Visiteur** : vous ne voyez que **Premiers pas** et **Bibliothèque**, et toute autre page vous ramène à **Premiers pas**.

Ouvrez **Premiers pas** → **Commencer les quêtes de bienvenue** et regardez quelle étape est encore **À faire** : **Complétez votre profil**, **Ajoutez une photo** ou **Assistez à une rencontre de la communauté**.

Les comptes clinique et le personnel de clinique ne voient jamais d'onglets : ils ont un seul menu (**Tableau de bord**, **Appareils**, **Pannes**, **Groupes**, **Bibliothèque**, **Tâches**, **Réseau**). Voir [Comment l'application est organisée](three-worlds.md).

### J'ai assisté à la rencontre mais je suis toujours Visiteur { #i-attended-the-talk-but-i-am-still-a-visitor }

L'animateur doit toucher **Confirmer la présence** après l'appel, et votre profil et votre photo doivent être faits aussi. Votre profil a besoin d'un nom, d'un pays, d'une ville et de quelques mots sur vous. Ouvrez ensuite n'importe quelle page : vous voyez *« Bienvenue dans la communauté ! »*.

### Je n'ai pas reçu l'e-mail { #i-didnt-get-the-email }

- Regardez dans vos **courriers indésirables** (spam) ou **promotions**.
- **Mot de passe** : sur la page de connexion, touchez **Réinitialiser le mot de passe**, tapez votre e-mail, touchez **Envoyer le lien**. Le lien marche pendant 60 minutes.
- **Vérification** : sur **Mon Profil**, touchez **Envoyer l'e-mail de vérification**.
- **Invitation d'un ingénieur ou d'une clinique** : demandez-lui de la renvoyer. Un lien d'invitation ne sert qu'une fois ; s'il dit *« Cette invitation a déjà été utilisée »*, connectez-vous simplement.
- **Ajouté par votre clinique** : demandez à l'administrateur de vérifier votre adresse dans **Groupes**, de vous retirer et de vous inviter à nouveau.

### « Un compte existe déjà pour cet e-mail » { #an-account-already-exists-for-this-email }

Connectez-vous d'abord avec ce compte, puis rouvrez le lien d'invitation : vous pouvez l'accepter avec votre compte actuel (**Accepter l'invitation**).

### J'ai oublié mon mot de passe { #i-forgot-my-password }

Sur la page de connexion : **Mot de passe oublié ?** → **Réinitialiser le mot de passe**.

## Appareils

### Pourquoi je ne peux pas enregistrer d'appareil ? { #why-cant-i-register-a-device }

La page *« Vous ne pouvez pas encore enregistrer d'équipement »* liste vos cliniques et la raison pour chacune :

| L'application dit | Ce que cela veut dire | Que faire |
| --- | --- | --- |
| *« L'enregistrement d'équipements se débloque une fois vos trois étapes d'accueil terminées. »* | Vous êtes encore Visiteur | Terminez vos étapes d'accueil |
| *« vous a nommé ; terminez vos étapes d'accueil »* | La clinique vous a nommé, mais vos étapes ne sont pas faites | Terminez vos étapes d'accueil |
| *« a répondu « pas maintenant » ; elle peut vous confirmer plus tard »* | La clinique ne vous a pas confirmé | Demandez-lui de toucher **Confirmer** dans son onglet **Ingénieurs** |
| *« en attente de sa rencontre clinique »* | La clinique s'est inscrite sans invitation et sa rencontre n'est pas encore confirmée | La clinique réserve sa rencontre ; un Connecteur de cliniques la débloque |
| *« Aucune clinique ne vous permet encore d'enregistrer ses équipements. »* / *« ne vous a pas nommé »* | Aucune clinique ne vous a nommé | [Invitez une clinique](invite-clinic.md), ou demandez à une clinique de vous ajouter comme ingénieur |

La règle : vous pouvez enregistrer des appareils pour une clinique quand elle vous nomme ingénieur responsable et que vos étapes d'accueil sont terminées, ou si vous l'administrez ; dans les deux cas, seulement une fois la clinique active.

### Ma clinique attend sa rencontre clinique { #my-clinic-is-waiting-for-its-clinic-talk }

Une clinique qui s'inscrit sans l'invitation d'un ingénieur (ou qui est créée depuis **Groupes**) attend une courte **rencontre clinique** avec la communauté. Tant qu'un Connecteur de cliniques ne l'a pas débloquée, **personne ne peut enregistrer ses appareils, pas même ses administrateurs**.

- Réservez la rencontre : **Configurez votre clinique → Rencontre clinique → Réserver la rencontre**. Pas de lien ? La communauté vous contactera.
- Plus rapide : demandez à un ingénieur que vous connaissez d'inviter votre clinique. Les cliniques invitées n'attendent pas.

### « Scanner un code QR » dit que je ne peux pas enregistrer d'appareil { #scan-a-qr-code-says-i-cant-register-a-device }

Le bouton **Scanner un code QR** de l'**Accueil** sert à enregistrer de nouveaux appareils. Pour ouvrir un appareil déjà enregistré, scannez son étiquette avec l'appareil photo de votre téléphone, ou ouvrez-le depuis **Appareils**.

### Qui peut voir mes appareils ? { #who-can-see-my-devices }

- **Toute personne qui a l'étiquette QR** : la page publique (nom, marque, numéro de série, statut, date d'entretien, manuels, pannes ouvertes). Pas les informations privées de la clinique.
- **La page privée de l'appareil** : les membres de votre clinique, l'organisation qui entretient l'appareil, la personne qui l'a enregistré, et vos ingénieurs responsables confirmés.
- **Les profils d'ingénieurs** : une ligne par appareil qu'ils ont enregistré. Vos administrateurs peuvent la masquer, ou masquer votre nom, dans **Groupes → votre clinique → Confidentialité**.

Voir [Suivre les appareils de votre clinique](clinic-devices.md#who-can-see-your-devices).

### Comment supprimer un appareil ? { #how-do-i-delete-a-device }

**Appareils** → **⋯** sur sa ligne → **Supprimer**. Seuls les administrateurs de la clinique et la personne qui l'a enregistré le peuvent. Les documents téléversés restent dans la bibliothèque.

## Pannes et réparations

### Je ne peux pas signaler de panne : on me demande de me connecter { #i-cant-report-a-fault-it-asks-me-to-sign-in }

Signaler une panne demande un compte. Demandez à votre clinique de vous ajouter (**Groupes → Inviter un utilisateur**), ou créez un compte.

### Personne ne répond à mon appel { #nobody-answers-my-call-for-an-engineer }

Vos ingénieurs responsables sont prévenus en premier. Après 20 minutes (**L'appareil est à l'arrêt**) ou 4 heures (**Cette semaine**), les ingénieurs de votre ville sont prévenus aussi. Vérifiez que votre clinique a des ingénieurs responsables (onglet **Ingénieurs**) et que sa région et son adresse sont remplies.

### Combien ça coûte ? { #how-much-does-it-cost }

L'application est gratuite. Le prix des réparations se convient entre la clinique et l'ingénieur et se paie hors de l'application : l'application ne fait que le noter.

### Je ne peux pas envoyer d'offre { #i-cant-send-offers }

Seuls les ingénieurs dont les étapes d'accueil sont terminées (Contributeurs) envoient des offres, et seulement pour les demandes dont ils ont été prévenus.

## Réglages

### Comment changer de langue ? { #how-do-i-change-the-language }

En bas du menu, choisissez **EN**, **ES** ou **FR**. Sur téléphone, touchez d'abord **☰**. Sur les pages publiques (page QR, connexion), les boutons de langue sont en haut. L'application garde votre choix tant que vous êtes connecté sur ce téléphone ou cet ordinateur.

### Comment passer en mode sombre ? { #how-do-i-switch-to-dark-mode }

Le bouton en forme de lune en bas du menu.

### Comment devenir animateur de rencontres ? { #how-do-i-become-a-talk-host }

Les animateurs sont membres des Bâtisseurs de communauté (rencontres de la communauté) ou des Connecteurs de cliniques (rencontres cliniques). Demandez à un Bâtisseur de communauté de faire de vous un candidat pour l'une de ces équipes. Voir [Comment fonctionne la communauté](community-guide.md).

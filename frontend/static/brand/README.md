# FixMyMedTech logo files

Served by the app at `/static/brand/<file>`, so the website and other tools can link to them
(for example `https://platform.fixmymedtech.org/static/brand/fixmymedtech-mark.png`).

| File | What it is | Use it on |
| --- | --- | --- |
| `fixmymedtech-mark.png` | The mark in colour (cross, pulse line, wrench, gear) | White or light backgrounds |
| `fixmymedtech-mark-black.png` | The mark in black | Print, QR tags, stamps |
| `fixmymedtech-mark-white.png` | The mark in white | Dark backgrounds, photos |
| `fixmymedtech-logo-stacked.png` | The mark above the name FixMyMedTech | Website header, documents, slides (white background) |
| `fixmymedtech-africa.png` | Africa logo in colour | Light backgrounds, 64px and larger |
| `fixmymedtech-africa-black.png` | Africa logo in black | Print |
| `fixmymedtech-africa-white.png` | Africa logo in white | Dark backgrounds |

Favicons live one level up in `/static/` (`favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`,
`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `site.webmanifest`). `/favicon.ico` is also
served at the site root.

All files are PNG rasters made from the current artwork. Do not scale them above their native size.
Usage rules: the FixMyMedTech design system.
